# Output Directory

Files in this directory are generated by the pipeline and are not meant to be
committed as source code.

Expected subdirectories:

```text
processed/   Cached train/test master CSVs and missingness reports
logs/        Timestamped logs from pipeline runs
results/     Evaluation tables such as model_results.csv
plots/       Generated comparison and diagnostic figures
checkpoints/ Optional Keras model checkpoints
```

`main.py` loads cached master DataFrames from `processed/` by default. Rebuild
them with:

```bash
python scripts/export_master_dataframes.py
```
